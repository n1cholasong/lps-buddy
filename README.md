# LPS-buddy

## Problem Statement

The role of the LPS (Leader Platoon Sergeant) is to lead the platoon and update commanders through structured reports, ensuring they are fully aware of the situation on the ground. However, composing these reports on WhatsApp and making edits on a small mobile screen is both challenging and inefficient.

## The Solution

**LPS Buddy** is an all-in-one tool designed to simplify and streamline the reporting process. It consolidates multiple report types into a single, mobile-friendly application, enabling faster and more efficient communication of the platoon status.

## Tech Stack 

- HTML5, CSS3, JavaScript
- Bootstrap 5 for responsive design
- FontAwesome for icons
- Vercel for hosting

## How to use

1. The web application is hosted on Vercel you may click [here](https://lps-buddy.vercel.app) to visit the site.
2. Choose the type of report you need by selecting one of the cards.
3. Fill in the form fields as required.
4. Generate the report and copy it to your clipboard for easy sharing.
